# 霓虹丑角

原创绘图、系统字体与 WebAudio 合成音效的中文扑克肉鸽小游戏。

在线游玩：https://x3163.github.io/poker-jester/

## 打开与操作
- 电脑双击 `index.html` 即可离线游玩；游戏脚本、界面和声音都在这一文件内。其余文件仅供在线主屏幕 Web App 使用。
- 点击或轻触最多五张牌，再按“出牌”或“弃牌”。小丑从左到右结算，可拖动或通过详情按钮换序。
- 声音：菜单“手机打开 / 声音”或暂停→设置，点“开启音效并测试声音”。这会记住音效开启；iOS 支持时切换播放音频模式，可能暂停其他 App 音乐。后台返回需再次点击恢复。没有保证系统媒体音量或硬件输出可听。

## iPhone 主屏幕打开
Safari 打开网址→页面菜单中的“共享”（某些布局直接点共享）→“添加到主屏幕”→“添加”。iOS 26 及更新版本保留“作为网页 App 打开 / Open as Web App”开启。较早系统使用本站的独立运行声明。无需 App Store 或 Apple 审核。

独立模式不是强制系统全屏，不解除方向锁，不保证刘海/状态栏/底部横条隐藏。网页内提供当前运行模式和操作帮助。横屏空间很短时，信息栏和牌桌/商店分区可滚动，操作按钮保留。

主屏幕版本需联网加载，没有 Service Worker 离线缓存。Safari 与主屏幕入口的本地存档可能独立；请在原入口“存档备份”导出 JSON，再在新入口导入。

## 存档与修复说明
- 完整操作结束后自动存档。计分/发牌动画中暂停、退出或刷新，回到上一个完整存档点，不保存半次出牌。
- 导入检查版本、格式、字段和牌组引用；导入前会确认替换。仅保存本机，无账户、无云端。
- 五张同点数保守按其中四张作“四条”，使用四条数值和等级；不会误判为高牌。摧毁至少保留一张牌；耗尽可用手牌时安全结束本轮。

所有图形和声音均为原创程序绘制/合成。本项目没有外部脚本、字体或音频依赖。
